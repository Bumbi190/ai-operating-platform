# Claude coding instructions – Omnira

Read [AGENTS.md](AGENTS.md) before starting work. In particular, **do not create a new branch, worktree, or PR before checking whether the same project/task already has an open PR or active branch**. Run `node scripts/atlas/pr-preflight.mjs` and retain its receipt. Reuse the existing approved PR if available; otherwise document why a distinct branch is needed.

Read the user's enabled Notion Skills when accessible, including [Git/PR preflight](https://app.notion.com/p/4077b977c5b881a0b2ace8ec4091b245) and [Omnira development standard](https://app.notion.com/p/4017b977c5b881fe85a3c8d0cc3db23c). Do not touch unrelated dirty or locked worktrees and do not weaken SDF-1 isolated broker worktrees.

These repo instructions are not a permission to merge, deploy, import data, send outreach, or change production schedules.
