## Maturity disclaimer

Version 1.0 describes both the Stage 1 scope and the future target architecture. Canonical status applies to the doctrine as a target architecture. Many described capabilities are future architecture and are not implemented.

## Implementation-state disclaimer

Canonical target architecture is not the same as implemented production state. The actual repository, schema, runtime, and deployment state is the authoritative source for what exists in production. Atlas and future implementations must distinguish between canonical target architecture, implemented, partially implemented, planned, not implemented, and deprecated.

## Authority disclaimer

This book provides architectural knowledge but grants no automatic execution authority. No document, memory, knowledge object, graph object, or model output may create authority without valid governance. Autonomous operating rights may be granted only by authorized governance through an approved autonomy license, following an Executive recommendation. The Executive must not grant itself authority or higher autonomy.
