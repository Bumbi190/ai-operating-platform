## 1. Root causes (confirmed)

| Defect | Location | Root cause in `build_professional_edition.py` |
|---|---|---|
| Truncated panel headers `PORTFOLIO EXECUTIVE ARCHIT` / `PROJECT EXECUTIVE ARCHITEC` | p117 (D03) | `_columns()` panel titles set via `_ctitle(...).upper()[:26]` — hard character truncation. |
| Truncated header `OPPORTUNITY COST INTELLIGE` | p667 (D08) | Same `[:26]` truncation on the second column title. |
| Cut autonomy labels L3–L6 | p934 (D12) | `dia_trust()` draws rotated bar labels via `c.rotate(90)` + `s[:22]`; rotated text overflows the bar height and is character-clipped. |

**Fix strategy (applies to every rebuilt asset):** labels always **wrap** to the available width — the
`.upper()[:N]` truncation is removed entirely; D12 uses **horizontal, full-length** labels with no
rotation. Corrected renders were rasterised to PNG at 120 dpi and inspected visually (see §4).

Secondary finding: diagrams **D03–D09** and **D13–D17** were generated by `make_titlenode_diagram(...)`,
which harvests a chapter's canonical section headings and lays them out as a **list**. A list of section
titles is not an architectural model. These are reclassified below and rebuilt into real models.
