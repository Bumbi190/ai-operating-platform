# Executive Intelligence — Professional Edition v1.0

## Diagram Specification (LOCKED — Phase 3.2)

All diagrams are reproducible vector art generated programmatically (ReportLab drawing /
matplotlib vector export). No raster images. Every label is derived directly from Canonical
v1.0 and is cited by section number in the Design Proof Report. Diagrams that would only
repeat text are avoided.

## 1. Visual language (LOCKED)

| Concept | Convention |
|---|---|
| Hard boundary — Project Isolation, Damage Boundary, constitutional limits, forbidden authority transitions | Solid line |
| Conditional / licensed boundary — autonomy license, time-limited authority, conditional delegation, trial authority | Dashed line |
| Implemented / Stage 1 | Solid fill, normal opacity |
| Future target architecture | Muted Ghost Grey tone or dashed outline, clearly labeled `FUTURE TARGET` or `NOT IMPLEMENTED IN STAGE 1` |
| Recommendation | Executive Gold (`#C8A24B`) |
| Governance / structural authority | Blueprint Navy / Petrol (`#1F3B57` / `#183850`) |
| Risk / violation | Damage Red (`#B4442E`) |
| Execution systems | Neutral navy / grey |

## 2. Reusable legend

A single consistent legend is defined once and reused across the whole book. It maps: solid =
hard boundary; dashed = conditional/licensed; solid fill = Stage 1 / implemented; ghost/dashed
= future target; gold = recommendation / executive judgment; navy/petrol = governance; red =
risk/violation; grey = execution. The legend appears with every diagram that uses more than
one convention.

## 3. Actor color coding

Each architectural actor keeps one fixed hue and position in all diagrams so the reader learns
the system once: Executive (leadership) top, gold-accented; Manager (coordination) middle,
navy; Workforce (execution) lower, neutral grey; Atlas (communication) at the user edge;
supporting intelligence layers (Memory, Knowledge, AI Intelligence, Performance) as evidence
surfaces; Omnira Constitution as the governing frame.
