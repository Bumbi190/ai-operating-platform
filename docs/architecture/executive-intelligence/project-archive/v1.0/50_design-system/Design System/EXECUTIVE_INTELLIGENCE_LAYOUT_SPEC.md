# Executive Intelligence — Professional Edition v1.0

## Layout Specification (LOCKED — Phase 3.2)

## 1. Page geometry

- Trim: US Letter, 8.5 × 11 in (612 × 792 pt), matching the Blueprint.
- Margins (light body pages): top 1.25 in, bottom 1.0 in, inside/left 1.15 in, outside/right 1.0 in.
- Running header baseline: 0.5 in from top; footer baseline: 0.55 in from bottom.
- Text measure (body): ~6.35 in, single column, left-aligned (ragged right) for even color
  and reliable spacing across long numbered sections.
- Dark feature pages (cover, part dividers, chapter openings, full-page diagrams) run to the
  full trim with no visible body margin rules.

## 2. Running header & footer

- Header (light pages): left = `OMNIRA · EXECUTIVE INTELLIGENCE — PROFESSIONAL EDITION`
  (DejaVu Sans, letterspaced, Slate); right = `Chapter N · Title`. A thin Petrol rule sits
  under the header.
- Footer: centered `Page X of Y` (DejaVu Sans). Chapter/section track may appear at the
  outside edge.
- Cover, title, and part dividers carry no running header/footer.

## 3. Front matter order

1. Cover (dark).
2. Title page (dark) — full metadata, canonical status, owner, version, approval date.
3. Document Control / Canonical Doctrine Notice (light) — Blueprint-style metadata table plus
   the Canonical Doctrine Notice reproduced verbatim.
4. Table of Contents (light) — live TOC with Part grouping, chapter entries, page numbers, and
   clickable internal links / PDF bookmarks.

## 5. Chapter opening (dark)

Dark surface. Small-caps mono eyebrow `CHAPTER N` with the number accented in Executive Gold,
followed by the chapter title (DejaVu Sans Bold) and the beginning of the actual canonical
chapter text. No invented preludes or summaries — the opening flows directly into the first
canonical section (e.g. `16.1 Purpose of This Chapter`).

## 6. Body page (light)

Single column. H2 section headings carry the canonical number (e.g. `16.1`). Canonical
numbered lines and short declarative statements retain their original line structure. Lists
use a thin en-dash / gold tick marker. Long chapters are broken with thin Petrol section
rules and consistent callouts so the reader never loses orientation.

## 7. Callout blocks

Eight locked callout types (see diagram spec §4 for color coding). Each is a boxed block with
a mono letterspaced label bar and verbatim canonical body text. Callouts are clearly
separated, restrained, consistent, legible, functional, and not brochure-like. They never
alter or summarize canonical meaning.

## 8. Tables

Blueprint-related aesthetic: Petrol (`#183850`) header row with Warm Paper text, light zebra
body rows, thin rules. Table content uses only information explicitly present in Canonical v1.0.

## 9. Diagram placement

Large system models are full-page (often dark feature pages); smaller relationships are
half-page or inline. All diagrams are reproducible vector art (see diagram spec).

## 10. Estimated full-book extent (not produced in Phase 3.2)

Approximately 380–480 pages in this format, to be confirmed by a structural render of the full
canonical text during Phase 3.3 production. Phase 3.2 produces only the limited proof.
