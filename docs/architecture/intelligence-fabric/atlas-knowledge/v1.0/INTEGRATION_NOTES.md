# Atlas Knowledge Integration Notes

The knowledge representation follows the repository's established canonical-book pattern:

- one Markdown file per canonical chapter;
- stable chapter and section anchors;
- YAML provenance metadata including source SHA-256;
- JSON indexes for chapters and parts;
- explicit `runtime_ingested: false` state;
- links back to canonical source and full-book artifacts.

The Markdown is a derived access format. It does not supersede the canonical DOCX/PDF edition and it does not assert implementation conformance.
