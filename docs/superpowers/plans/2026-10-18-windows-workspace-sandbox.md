## Review Focus

1. A directory/config is replaced between inspection and Git use: hold validated handles through use, refuse replacement, recheck identity and never write through a substituted ancestor. Task 1 native held-directory rename/reparse and held-config-write tests; Task 2 changed-evidence refusal.
2. Repository/global environment causes Git to launch hooks, filters or credential tooling: the actual child receives a fresh environment and exact finite command grammar; local config audit and native sentinel tests prove no helper execution. Task 2.
3. Docker named-pipe peer changes on reconnect or mutation response is lost: validate the actual request stream's peer before bytes, never transparently retry mutation; reconcile/remove only the current attempt's owned container. Task 3 wrong-peer-zero-bytes and lost-create tests.
4. Two callers share a workId or the base ref moves during creation: collision is a refusal, never reuse/reset; any post-mutation uncertainty is retained and marked unverified. Task 2 native concurrent/collision/base-drift cases.
5. Timeout/helper death leaves a Git child or a probe resource: Job Object closes Git descendants; probe cleanup uses the retained attempt identity and exact ownership checks, and failures report retained cleanup. Task 1 process-tree test and Task 3/4 cleanup recovery tests.
