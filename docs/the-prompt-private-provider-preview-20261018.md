## Execution and durable no-replay boundary

GET is read-only: it returns a quote or existing state. POST requires exact same origin, a small strict JSON body, the current server quote hash and the exact 12 SEK cap. No paid GET or automatic polling generation exists.

Before claiming: source freshness, all three credentials, strict existing budget gate, conservative sum of all provider ceilings (including primary and credit-refusal fallback planners), original source metadata on the fixed official URL, a second freshness/quote check after the network read, and canonical project stop authority.

The existing media_jobs provider vocabulary does not cover Ideogram/ElevenLabs, so this path does not pretend they are MuAPI jobs or change that schema. A media_scripts row with a deterministic input identity is inserted ONCE using its actual unique primary key. PostgreSQL duplicate refusal is the race arbiter; no process-local mutex grants execution.

The row has pending_review status, private_preview video status, empty legacy media fields, and the persisted illustration-profile marker. It cannot become an automatic publishing candidate. Step2 and the central Lambda starter also hold marked rows even when flags are switched off.

A claimed row is never regenerated by another POST, including after a timeout, restart, partial success or ambiguous provider error. Image IDs are checkpointed individually. The canonical voice receipt is stored with the audio ID and actual word timings. A failure becomes review_required when persistence allows; an unchanged claimed row still prevents replay if saving failed. Human reconciliation/retry tooling is outside this one-probe path.
